# Mower POV

Implement a fixed mower camera, real-scale motion, persistent grass state, and repeatable video.
Use [the design](docs/design.md) and [the implementation plan](docs/implementation-plan.md).

Run the relevant unit tests for state or motion changes. Render and inspect representative
frames and a contiguous segment for render changes. Record whether audio was auditioned.
Keep runs and the local tool installation out of Git. Public publishing, website changes,
and paid compute require separate authorization.
