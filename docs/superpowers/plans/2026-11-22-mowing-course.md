# 多行草坪作业片实施计划

沿用固定 22 厘米机载相机、长草根身份和可重放的刀盘状态。增加一个独立的
`mowing-course` 场景，保留 40 秒成片所用的场景和命令。

1. 建立五行往返参考路线、相邻行回转和家庭障碍物的米制布局。用相同几何计算
   名义路线、实际底盘轮廓净距和 Blender 道具。先让轨迹、净距和旧草带测试失败。
2. 对被阻塞的直行检测障碍并比较绕行候选。以持续净距、偏移距离、回接与重复作业
   为约束，按曲率和加速度限制执行。把计划、绕行、回接和换行状态写入缓存。
3. 在原庭院摆入水管、浇水壶和球。用第一轮俯视与机载帧核对物件可见性、
   运动余量及已割草带。按测试和画面调整一次场景，再渲染连续验收段。
4. 使用验证通过的同一缓存渲染超过一分钟的主片。检查实际曝光、所有帧、分段、
   音轨对齐、原速播放和逐帧状态。把主片、证据、配置、复现命令交付在本地。
