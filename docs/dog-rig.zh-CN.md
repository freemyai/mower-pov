# 短毛犬资产与接触验证

犬只的造型、骨架、蒙皮、毛色和短毛均由本项目的原创代码生成，随项目以 GPL-3.0-or-later 发布。模型未使用第三方素材、扫描数据或外部贴图。动态场景默认使用此犬只，旧场景的调试代理用于复现先前版本。[生成代码](../src/mower_pov/rendering/blender_dog.py) · [项目许可](../LICENSE)

模型以米为单位，鼻端朝局部 +X。Blender 将躯干、头颈、四肢、脚掌、耳和尾的截面融合成一个封闭连续的皮肤网格，共 54,054 个顶点。21 根骨骼分别控制躯干、头颈、耳、尾及四条腿。权重按截面位置、距骨段的距离和关节过渡分配。22,000 根顺着表面毛流生成的短毛继承根部皮肤权重。支撑期保持脚掌朝向和接触点，腿部根据地形高度求解固定长度的上、下骨段。[步态求解](../src/mower_pov/actors/gait.py)

在 Blender 5.2.4 中以 60 Hz 从每段轨迹开始前 0.05 秒采样至结束后约 0.10 秒。以地形采样高度减去所有变形后皮肤顶点的世界 Z 值找最大穿地深度。对同一支撑接触，以首个采样点为基准，跟踪脚掌骨权重大于 0.999、静止姿态高度低于 3 毫米的脚底顶点。

| 犬只轨迹 | 最大脚底漂移 | 最大皮肤穿地 |
| --- | ---: | ---: |
| 旧版后院，17.6–22.8 秒 | 0.000592 毫米 | 3.884 毫米 |
| 动态横穿，8.2–13.6 秒 | 0.000993 毫米 | 3.426 毫米 |

侧面、斜前方和 22 厘米高度的独立资产诊断图用于检查轮廓、四肢与躯干衔接及脚底贴地。19 帧连续样片使用 30 fps，覆盖旧版轨迹 19.97–20.57 秒，未配音。诊断素材保存在本地 `runs/dynamic-revision/rig/`，动态场景的机载验收使用固定在割草机上的相机。犬只采用简化的短毛犬解剖结构，快速小跑时弯折的后腿会与其他肢体互相遮挡。接触测量基于连续地形表面，不含草叶和毛尖。

```sh
MOWER_BLENDER=.tools/blender-5.2.4-linux-x64/blender .venv/bin/python -m pytest -q \
  tests/integration/test_skinned_dog.py tests/test_grounded_gait.py
```
